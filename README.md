# Saveiy :: Main Websie

Build a modern SaaS website for a startup called Saveiy.

Concept:
Saveiy is a subscription intelligence platform that helps users discover, track, and save money on their digital subscriptions (Netflix, Spotify, YouTube, SaaS tools, etc.).

The website design should be inspired by Rocket Money, but with its own visual identity and personality.

Design Direction

Clean fintech-style UI

Friendly but intelligent product tone

Smooth animations and micro-interactions

Rounded cards and soft shadows

Soft gradients and minimal clutter

Mobile-first responsive design

Color vibe:

Primary: teal / mint green (symbolizing savings)

Secondary: dark navy or charcoal

Accent: soft purple or electric blue

Style inspiration:

Rocket Money

Ramp

Notion

Stripe product pages

But make the branding feel fresh and playful, not a copy.
